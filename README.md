\# PHP CRUD DevOps Project



A production-style PHP CRUD application deployed on Kubernetes using Docker, KIND, NGINX Ingress Controller, GitHub Actions CI/CD, ConfigMaps, Secrets, and Persistent Storage.



\## Tech Stack



\- PHP

\- MySQL

\- Docker

\- Kubernetes (KIND)

\- NGINX Ingress

\- GitHub Actions

\- ConfigMaps

\- Secrets

\- Persistent Volumes



\## Features



\- CRUD Operations

\- Containerized Application

\- Kubernetes Deployment

\- CI/CD Pipeline

\- Secret Management

\- Persistent Storage

\- Health Checks

\- Failure Simulation \& Debugging
